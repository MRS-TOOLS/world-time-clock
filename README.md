# World Time Comparator

基準地域の日時を、複数の国・地域の現地日時へ変換して比較するMRS TOOLS向けWebツールです。

## 主な機能

- 基準地域は初期状態で「日本・東京」
- 現在時刻とのリアルタイム連動
- 基準日時の手動入力と一括変換
- 国選択、地域選択、検索
- 比較地域の複数追加と削除
- サマータイム適用中の表示
- 地域ごとの「サマータイム無視」切り替え
- ドラッグによる基準地域と表示順の変更
- 選択地域や設定の端末内保存

## 構成

- `index.html` — 画面構造
- `style.css` — スマートフォン優先の表示
- `script.js` — 時差計算、操作、端末保存
- `timezones.js` — 国・IANAタイムゾーン一覧
- `service-worker.js` — 本体ファイルのオフラインキャッシュ

外部APIやサーバー通信は使用せず、ブラウザの `Intl` APIで時差を計算します。

## オフライン利用

一度オンラインでページを開き、Service Worker のインストールが完了すると、通信がない状態でも時計本体を再読み込みできます。広告と MRS TOOLS への外部リンクはオフラインでは利用できません。端末のストレージ削除やブラウザによるキャッシュ削除後は、再度オンラインで開く必要があります。

取得済みの時計本体は、通常オンライン・低速／不安定通信・完全オフラインのいずれでもキャッシュを優先して起動します。広告通信の成功を本体起動の条件にはしません。キャッシュ欠損時の本体取得は、接続と本文ダウンロードを合わせて最大8秒で打ち切ります。入口ページを取得できない場合は、再試行の案内を表示します。初回アクセスなど、まだService Workerに制御されていないページの通信にはこの上限は適用されません。

本体ファイルを更新する際は `index.html` の CSS/JS の `?v=`、`service-worker.js` の `APP_FILES` を一致させ、`CACHE_NAME` のバージョンを上げてください。全ファイルを取得・保存できた新版だけを採用し、取得失敗時は既存版を維持します。使用中の版のファイルを通信結果で個別に上書きしません。

更新は既存のタブ・ホーム画面アプリの画面をすべて閉じた後に切り替わります。再読み込みだけでは切り替わらない場合があります。旧キャッシュは切り替え時に、このアプリの接頭辞に一致する範囲だけ削除します。保存済みの地域・設定のlocalStorageは変更・削除しません。

### 弱回線・更新の検証

`node --test tests/service-worker.test.cjs` で、通常通信・応答ハング・本文ハング・完全オフライン・HTTPエラー・更新失敗・入口URL・キャッシュ削除範囲を検証します。iPhone / Safariとホーム画面の実機確認は別途必要です。

## ホーム画面への追加（PWA）

Safari の共有メニューから「ホーム画面に追加」を選ぶと、世界時差時計を独立した画面で開けます。iPhone では「Webアプリとして開く」を有効にしてください。初回はオンラインで開き、Service Worker のキャッシュが完了するとオフラインでも本体を利用できます。ホーム画面に追加したアプリの保存領域は Safari と別になるため、Safari で選択済みの地域は自動では引き継がれません。アプリ内で再設定してください。

- `manifest.webmanifest` — アプリ名・起動URL・表示モード・アイコン
- `pwa-icon.svg` — アイコンの編集用原本とブラウザ用アイコン
- `icon-192.png` / `icon-512.png` — PWA アイコン
- `apple-touch-icon.png` — iPhone のホーム画面用アイコン

更新時は `service-worker.js` のキャッシュバージョンと対象ファイルを更新してください。
